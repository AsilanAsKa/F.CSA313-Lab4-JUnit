# F.CSA313 Лаборатори 4 — JUnit 5 нэгжийн тест

**Оюутны нэр:** Асилан Серикбай
**Оюутны код:** B232270115

Энэ лабораторийн ажлаар Maven болон JUnit 5 ашиглан нэгжийн тест бичиж, `GradeCalculator` классын үйл ажиллагааг шалгасан. Лабораторийн ажлыг OpenJDK 21.0.12 болон Apache Maven 3.8.7 орчинд гүйцэтгэсэн бөгөөд Java хувилбарыг Maven compiler дээр 17 болгон тохируулсан. Нийт 11 тестийн арга бичсэн бөгөөд параметртэй тестийн мөрүүдийг тусад нь тооцоход нийт **21 тест** ажилласан. Бүх тест амжилттай ажиллаж, `Tests run: 21, Failures: 0, Errors: 0, Skipped: 0` болон `BUILD SUCCESS` үр дүн гарсан. `letterGrade` функцэд 90, 89.99, 60, 59.99, 0, 100 зэрэг хязгаарын утгуудыг болон буруу утга оруулах үеийн `IllegalArgumentException` алдааг шалгасан. Мөн `totalScore` функцийн зөв нийлбэр, сөрөг утга, зөвшөөрөгдөх дээд хэмжээнээс их утгыг шалгасан. Mutation testing хийхдээ `score >= 90` нөхцөлийг түр хугацаанд `score > 90` болгон өөрчлөхөд `letterGradeBoundaries(double, String)[2]` тест амжилтгүй болж, `expected: <A> but was: <B>` болон `BUILD FAILURE` үр дүн гарсан. Энэ нь 90 онооны хязгаарын тест програмын алдааг илрүүлж байгааг харуулсан бөгөөд дараа нь нөхцөлийг буцаан зөв болгож, бүх 21 тестийг дахин амжилттай ажиллуулсан. Тестийн үр дүнг `results/mvn-test.txt` болон mutation testing-ийн үр дүнг `results/mvn-test-mutant.txt` файлд хадгалсан.
