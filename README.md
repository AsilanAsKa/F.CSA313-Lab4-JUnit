## Ажлын тайлбар

Энэ лабораторийн ажлаар Maven болон JUnit 5 ашиглан нэгжийн тест бичиж, `GradeCalculator` классын үйл ажиллагааг шалгасан. Нийт **12 тестийн метод** бичсэн бөгөөд parameterized тестийн мөрүүдийг тусад нь тооцоход нийт **21 тест** ажилласан. Бүх тест амжилттай ажиллаж, `Tests run: 21, Failures: 0, Errors: 0, Skipped: 0` болон `BUILD SUCCESS` үр дүн гарсан. `letterGrade` методод 95, 85, 75, 65, 30 гэсэн ердийн утга болон 90, 89.99, 60, 59.99, 0, 100 гэсэн хязгаарын утгуудыг шалгаж, -1 болон 101 зэрэг буруу утгад `IllegalArgumentException` үүсэхийг шалгасан. `totalScore` методод зөв нийлбэр, сөрөг утга болон зөвшөөрөгдөх дээд хэмжээнээс хэтэрсэн утгуудыг шалгасан. Mutation testing хийхдээ `score >= 90` нөхцөлийг түр `score > 90` болгон өөрчлөхөд `letterGradeBoundaries(double, String)[2]` тест унаж, `expected: <A> but was: <B>` болон `BUILD FAILURE` гарсан. Энэ нь 90 онооны хязгаарын тест програмын алдааг зөв илрүүлж байгааг харуулсан бөгөөд дараа нь нөхцөлийг буцаан засаж, бүх 21 тестийг дахин амжилттай ажиллуулсан. Тестийн ногоон болон mutation-ийн үр дүнг `results/mvn-test.txt`, `results/mvn-test-mutant.txt` файлд хадгалсан.
